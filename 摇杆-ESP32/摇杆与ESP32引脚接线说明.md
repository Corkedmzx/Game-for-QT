# 模拟摇杆扩展板与 ESP32 引脚对照

本文档说明与本工程固件一致的接线方式。引脚定义以 `main/main.c` 中的宏为准。

## 适用硬件

- **摇杆模块**：Keyes 类模拟摇杆扩展板（双排针、带 X/Y 模拟量及多颗侧键 + 中央按键 K）。
- **开发板**：与本工程配套的 ESP32-S3 板（固件使用板载 WS2812 时占用 **GPIO48**，与摇杆无电气冲突）。

## 电源与共地

| 摇杆排针丝印 | 接 ESP32 |
|--------------|----------|
| **GND** | **GND**（必须与开发板共地） |
| **V / 3V3** | **3V3**（按模块标识接 3.3 V；勿超过模块允许电压） |

## 模拟轴（ADC）

摇杆电位器两轴对应开发板 **GPIO6、GPIO7**，由固件经 ADC 读取。

| 功能 | ESP32 GPIO | 说明 |
|------|------------|------|
| **X 轴** | **GPIO6** | 水平方向模拟量 |
| **Y 轴** | **GPIO7** | 垂直方向模拟量 |

## 按键（数字输入，内部上拉）

扩展板侧键 A～F 与中央键 K 分别接到连续 GPIO；固件配置为**内部上拉**，**按下多为低电平**。

| 按键 | ESP32 GPIO |
|------|------------|
| **A** | **GPIO9** |
| **B** | **GPIO10** |
| **C** | **GPIO11** |
| **D** | **GPIO12** |
| **E** | **GPIO13** |
| **F** | **GPIO14** |
| **K**（中央键） | **GPIO15** |

## 排针对应关系（便于对照丝印）

扩展板**右侧双排针**按工程注释：竖列为一对。与本表 GPIO 一一对应即可；若你手上的模块丝印与 Keyes 扩展板略有差异，请以**功能名**（X、Y、A…K、GND、电源）为准接到上表 GPIO。

## 修改软件中的引脚

若实际接线与上表不同，请修改 `main/main.c` 中的宏：

- `JOY_X_GPIO`、`JOY_Y_GPIO`
- `BTN_GPIO_A` … `BTN_GPIO_K`

修改后需重新编译并烧录固件。
